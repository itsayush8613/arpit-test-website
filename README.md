# THE ARPIT TEST

An interactive, playful quiz website with a modern glassmorphism design and fun interactions.

## Features

- 🎨 **Modern Glassmorphism Design** - Dark background with glowing gradient effects
- 📱 **Fully Responsive** - Optimized for mobile, tablet, and desktop
- ✨ **Smooth Animations** - Elegant transitions and entrance animations
- 🎯 **Playful Interactions** - The NO button runs away from clicks!
- 💬 **Random Toast Messages** - Fun notifications during quiz
- 🏆 **Results Screen** - Engaging results summary

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Glassmorphism, gradients, animations, and responsive design
- **Vanilla JavaScript** - Interactive quiz logic
- **Google Fonts** - Caveat and Fredoka One fonts

## File Structure

```
├── index.html      # Main HTML structure
├── styles.css      # All styling and animations
├── script.js       # JavaScript logic for quiz functionality
└── README.md       # This file
```

## How to Use

1. Clone the repository
2. Open `index.html` in your browser
3. Answer the 5 questions about Arpit
4. Try to click the NO button (it runs away!)
5. See your results at the end
6. Restart the quiz anytime

## Quiz Questions

1. Do you like Arpit? 👀
2. Would you trust Arpit with your Spotify password? 🔐
3. Is Arpit cool asf? 😎
4. Does Arpit deserve a Grammy for his music taste? 🏆
5. Is Arpit's Spotify playlist better than yours?? 🎧

## Customization

You can easily customize:

- **Colors**: Edit CSS variables in `:root` in `styles.css`
- **Questions**: Modify questions in `index.html` or add new ones
- **Toast Messages**: Update the messages array in `script.js`
- **Animations**: Adjust animation durations and easing functions in `styles.css`
